FREE HOSTING OPTION
-------------------
Recommended: GitHub Pages or Cloudflare Pages.

GitHub Pages basic process:
1. Create a free GitHub account.
2. Create a public repository called realestatewithzara.
3. Upload index.html, styles.css, and script.js.
4. Open repository Settings > Pages.
5. Deploy from your main branch/root.
6. GitHub will give you a temporary github.io URL.
7. Add realestatewithzara.com as the custom domain.
8. GitHub will show the DNS records to add at Namecheap.
9. In Namecheap > Domain List > Manage > Advanced DNS, replace the current redirect with the records GitHub gives you.
10. Enable HTTPS after DNS finishes propagating.

IMPORTANT:
Do NOT point your domain directly at the Sierra subdomain unless that is what you decide you want.
